# 中文接口文档编写

`api-docs-zh` 帮助 Codex 将项目代码或第三方协议整理成供厂商联调的中文 Markdown 文档。它会追踪关联字段的来源，把字典编码逐行展开，并写明业务成功的判断条件和失败后的处理方式。

## 安装到 Codex

```sh
npx skills add kasen1015/api-docs-skills --skill api-docs-zh -a codex -g
```
